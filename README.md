# Курсовая работа «DevOps-инженер с нуля»

Анастасия Колесникова.

Работа выполняется. В репозитории размещены Terraform и Ansible для развёртывания инфраструктуры. Результаты реальных проверок и снимки экрана будут добавлены после завершения развёртывания.

Условия курсовой включают отказоустойчивый сайт, мониторинг Prometheus и Grafana, логи Elasticsearch и Kibana, bastion и резервное копирование. Выполняются также все дополнительные пункты, включая Managed PostgreSQL, Instance Group, Alertmanager, сбор внутренних логов и HTTPS.
